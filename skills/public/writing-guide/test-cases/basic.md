# 写作指导技能 - 测试用例

本文档包含验证技能功能的测试用例。

---

## 测试用例 1：文本润色 - 错别字检测

### 输入
```
帮我看看这段话有没有错别字：
今天天气真好，我和朋友们一起去公园玩。我们看了漂浪的花，玩了有趣的游戏，开心极了！
```

### 预期输出
- 检测到错别字："漂浪" -> "漂亮"
- 其他修改建议（如有）
- 统计修改数量

### 验证标准
- [ ] 正确识别"漂浪"为错别字
- [ ] 提供正确的修改建议
- [ ] 格式符合输出规范

---

## 测试用例 2：文本润色 - 句式优化

### 输入
```
润色这段话：
我觉得这个产品吧，真的是特别特别的好的
```

### 预期输出
- 精简冗余（"特别特别"）
- 调整句式使其更流畅
- 保持原意

### 验证标准
- [ ] 识别重复词
- [ ] 优化后语句通顺
- [ ] 给出修改说明
