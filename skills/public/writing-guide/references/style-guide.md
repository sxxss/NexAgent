# 文风调整指南

本文档提供不同文风的特点和调整方法。

---

## 文风类型

| 文风类型 | 适用场景 | 特点 |
|----------|----------|------|
| 正式 | 报告、合同、官方文件 | 严谨、规范、专业术语 |
| 活泼 | 社交媒体、博客 | 轻松、有趣、口语化 |
| 学术 | 论文、学术文章 | 客观、引用、逻辑性强 |
| 文艺 | 散文、诗歌 | 优美、抒情、意境 |
| 商务 | 邮件、提案 | 简洁、专业、结果导向 |
| 温馨 | 祝福信、慰问信 | 亲切、关怀、情感丰富 |

---

## 正式文体特征

### 词汇特征

| 口语词 | 改为正式 |
|--------|----------|
| 碰巧 | 恰逢 |
| 很多 | 诸多 |
| 搞 | 进行 |
| 觉得 | 认为 |
| 必须要 | 必须 |
| 好 | 良好 |

### 句式特征

- 使用完整句式
- 避免感叹句和疑问句
- 减少修辞手法
- 使用被动语态

### 示例

**原文（口语）**：
> 这个事情我觉得吧，得先看看能不能做，然后再跟领导汇报一下。

**改写（正式）**：
> 此项工作需先评估可行性，随后向领导汇报。

---

## 活泼文体特征

### 词汇特征

| 正式词 | 改为活泼 |
|--------|----------|
| 因此 | 所以 |
| 然而 | 但是 |
| 非常 | 特别 |
| 迅速 | 飞快 |
| 小心 | 注意啦 |

### 句式特征

- 多用短句
- 适当使用感叹词
- 使用口语化表达
- 增添趣味性

### 示例

**原文（正式）**：
> 本产品具有高效、节能、环保等优势。

**改写（活泼）**：
> 这款产品真的太棒了！高效又节能，还特别环保，简直是居家必备神器！

---

## 学术文体特征

### 词汇特征

- 使用专业术语
- 避免口语化表达
- 使用客观陈述
- 引用权威观点

### 句式特征

- 使用复杂句式
- 逻辑连接词丰富
- 论证层层递进
- 结论谨慎保守

### 示例

**原文**：
> 我觉得这个理论很有道理。

**改写（学术）**：
> 根据XXX的研究成果（2023），本理论具有较强的解释力，这在后续研究中被多次验证。

---

## 文艺文体特征

### 词汇特征

- 使用修辞手法
- 形象化表达
- 注重音韵和谐
- 情感丰富

### 句式特征

- 长短句交错
- 使用排比、对偶
- 留白艺术
- 意境营造

### 示例

**原文**：
> 春天来了，花开了。

**改写（文艺）**：
> 春风拂过大地，万物苏醒。那满山的花朵，如朝霞般绚烂，悄然绽放着生命的奇迹。

---

## 商务文体特征

### 词汇特征

| 词汇类型 | 示例 |
|----------|------|
| 行动导向 | 推进、落实、执行 |
| 结果导向 | 达成、实现、提升 |
| 专业术语 | ROI、KPI、闭环 |
| 谦敬语 | 感谢、期盼、荣幸 |

### 句式特征

- 开门见山
- 结论先行
- 条理清晰
- 数据支撑

### 示例

**原文**：
> 我们想跟您约个时间聊聊合作的事情。

**改写（商务）**：
> 为进一步探讨合作细节，诚邀贵方于本周五下午2点进行面谈。

## 文风转换技巧

### 1. 词汇替换表

```
# 口语 -> 正式
我 -> 本人/本人
你 -> 贵方/您
要 -> 需要/应当
不能 -> 无法/不可
但是 -> 然而/但是
所以 -> 因此/故

# 正式 -> 口语
因此 -> 所以/于是
然而 -> 不过/但是
此外 -> 还有/另外
鉴于 -> 因为/由于
导致 -> 造成/使得
```

### 2. 句式转换

```
# 复合句 -> 简单句
由于天气原因，会议推迟。 -> 天气不好，会议推迟了。

# 被动 -> 主动
问题已被解决。 -> 我们解决了这个问题。

# 陈述 -> 祈使
请尽快回复。 -> 麻烦您抽空回复一下~
```

### 3. 段落调整

| 目标 | 技巧 |
|------|------|
| 更简洁 | 删除冗余修饰语 |
| 更丰富 | 添加细节描写 |
| 更正式 | 增加连接词 |
| 更活泼 | 拆分长句 |
