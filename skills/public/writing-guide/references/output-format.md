# 写作指导输出格式规范

本文档定义了写作指导技能的统一输出格式。

---

## 一、文本润色输出格式

### 1.1 完整润色报告

```markdown
## 📝 润色结果

### 原始文本
[用户输入的原文]

### 优化后文本
[润色后的文本]

### 修改明细

| 位置 | 原文 | 修改后 | 类型 | 原因 |
|------|------|--------|------|------|
| 第2句 | xxx | xxx | 错别字 | 同音字错误 |
| 第3段 | xxx | xxx | 句式 | 精简冗余 |

### 统计
- 错别字纠正：X 处
- 语法修正：X 处
- 句式优化：X 处
- 字数变化：X -> Y
```

### 1.2 快速润色（仅输出结果）

```markdown
## 📝 润色结果

[优化后的文本]
```

## 二、写作辅导输出格式

### 2.1 完整辅导报告

```markdown
## 📚 写作辅导

### 题目分析
[对写作题目/主题的分析]

### 文体判定
[确定的文体类型]

### 大纲设计

**一、引言** (约X字)
- 写作要点：xxx
- 示例：xxx

**二、主体** (约X字)
1. 第一个分论点
   - 论点：xxx
   - 素材：xxx
   
2. 第二个分论点
   - 论点：xxx
   - 素材：xxx

**三、结尾** (约X字)
- 写作要点：xxx
- 升华方向：xxx

### 素材推荐

**名言警句**
- xxx —— xxx

**典型事例**
- xxx：xxx

### 注意事项
- xxx
```

### 2.2 大纲简配版

```markdown
## 📚 写作大纲

**题目**：xxx

**结构**：
1. 开头：xxx
2. 主体：
   - 论点1：xxx
   - 论点2：xxx
   - 论点3：xxx
3. 结尾：xxx

**核心素材**：xxx
```

## 三、模板输出格式

### 3.1 完整模板

```markdown
## 📄 [文体名称] 模板

### 文体特点
- xxx
- xxx

### 适用场景
- xxx
- xxx

### 模板结构

[模板内容，含占位符]

### 示例

[完整示例一篇]

### 写作要点
1. xxx
2. xxx
3. xxx
```

### 3.2 简易模板

```markdown
## 📄 [文体名称] 模板

[简化的模板结构]
```

---

## 四、错误提示格式

```markdown
## ⚠️ 提示信息

[具体提示内容]
```

| 错误类型 | 提示文案 |
|----------|----------|
| 文本过短 | 文本过短（少于20字），无法进行有效润色。请补充更多内容。 |
| 文本过长 | 文本较长，已分段处理。 |
| 格式不支持 | 暂不支持此文本格式，请提供纯文本。 |
| 内容违规 | 无法对包含不当内容的文本进行润色。 |
