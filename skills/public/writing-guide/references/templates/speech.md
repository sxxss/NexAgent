# 演讲稿模板

## 文体特点

- **语言口语化**：便于朗读和听力理解
- **感情充沛**：能够打动听众
- **结构清晰**：层次分明，易于理解
- **控制时长**：根据场合控制篇幅

## 模板结构

```
【标题】：XXX

【开场】：
- 称呼：尊敬的XXX/亲爱的XXX
- 问候：大家好！
- 引题：今天我想和大家分享……

【正文】：

一、XXX（第一个要点）
- 事例/数据：XXX
- 观点：XXX

二、XXX（第二个要点）
- 事例/数据：XXX
- 观点：XXX

三、XXX（第三个要点）
- 事例/数据：XXX
- 观点：XXX

【高潮】：XXX（情感最高点）

【结尾】：
- 总结：今天我们讲到……
- 号召：让我们一起……
- 感谢：谢谢大家！
```

## 各类演讲场景模板

### 1. 开学/毕业典礼演讲

```
尊敬的各位老师、亲爱的同学们：

大家好！我是XX级的XXX。今天站在这里，我的心情……

[回忆校园生活]

[分享成长感悟]

[展望未来]

最后，我想用一句话结束今天的演讲：……

谢谢大家！
```

### 2. 竞选演讲

```
尊敬的各位领导、各位同事：

大家好！我是来自XX部门的XXX。今天竞选的岗位是XXX。

[自我介绍]

[优势分析]

[工作设想]

如果大家信任我，我会……

谢谢大家！请投我一票！
```

### 3. 开业/庆典致辞

```
尊敬的各位来宾、朋友们：

大家上午好！/大家晚上好！

[感谢到场]

[回顾历程]

[展望未来]

[祝福致谢]

谢谢大家！
```

## 演讲技巧

| 环节 | 技巧 |
|------|------|
| 开场 | 用故事、数据、问题吸引注意力 |
| 主体 | 3个要点为宜，每个要点配一个故事/案例 |
| 高潮 | 情感升华，呼告、反复等修辞 |
| 结尾 | 简洁有力，升华主题 |

## 字数参考

| 场景 | 参考时长 | 对应字数 |
|------|----------|----------|
| 5分钟 | 约600-800字 |
| 10分钟 | 约1200-1500字 |
| 20分钟 | 约2500-3000字 |
| 30分钟 | 约4000-4500字 |

## 写作要点

1. **三"忌"三"要"**
   - 忌照本宣科，要自然流畅
   - 忌空洞说教，要以情动人
   - 忌冗长拖沓，要简洁有力

2. **语言节奏**
   - 长短句交替
   - 适当重复强调
   - 使用排比增强气势

3. **肢体配合**
   - 眼神交流
   - 适度手势
   - 站姿稳健
