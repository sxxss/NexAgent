# 新闻稿模板

## 文体特点

- **真实性**：新闻的生命，事实准确
- **时效性**：快速报道新近发生的事件
- **客观性**：用事实说话，不掺杂个人情感
- **简洁性**：语言简练，信息量大

## 新闻要素（5W1H）

| 要素 | 英文 | 说明 |
|------|------|------|
| 何时 | When | 时间 |
| 何地 | Where | 地点 |
| 何人 | Who | 人物 |
| 何事 | What | 事件 |
| 为何 | Why | 原因 |
| 如何 | How | 过程 |

## 模板结构

### 1. 倒金字塔结构（最常用）

```
【标题】：概括核心事件（简洁、有吸引力）

【导语】：一句话概括最重要的新闻事实（5W1H）

【主体】：
- 补充导语中的细节
- 按重要程度递减排列
- 背景信息

【结尾】：可选，补充说明或展望
```

### 2. 并列式结构

用于报道多个相关事件或同一主题的不同方面。

## 标题类型

| 类型 | 示例 | 特点 |
|------|------|------|
| 主题式 | 国务院发布2024年中央一号文件 | 概括核心 |
| 主题+副题 | 人工智能带来教育变革：技术赋能个性化学习 | 补充说明 |
| 提问式 | 共享单车押金去哪儿了？ | 引发思考 |
| 引语式 | "我们要让每个孩子都接受优质教育" | 增强感染力 |
| 数字式 | 3年增长10倍：新能源汽车销量创新高 | 突出数据 |

## 导语写作

### 标准的导语

```
[时间]，[地点]讯 记者XXX报道：[核心事件一句话概括]
```

### 示例

```
2024年3月15日，北京讯 记者李明报道：国务院今日发布《关于全面推进乡村振兴的意见》，明确提出到2035年乡村振兴取得决定性进展。
```

## 主体写作要点

1. **段落简洁**：每段50-100字
2. **逻辑清晰**：按重要性或时间顺序
3. **引用原话**：增加真实性和权威性
4. **使用数据**：增强说服力
5. **背景补充**：帮助读者理解

## 各类新闻稿模板

### 1. 会议新闻

```
【标题】：XXX会议召开/XXX会议圆满落幕

【导语】：X月X日，XXX会议在XXX召开/举行。会议XXX主持，XXX出席并讲话。

【正文】：
会议首先……

会议强调……

会议指出……

会议要求……

会议还……

【结尾】：会议达到了预期目的，与会人员表示……
```

### 2. 活动新闻

```
【标题】：XXX活动成功举办/XXX活动正式启动

【导语】：X月X日，XXX活动在XXX举行。本次活动由XXX主办，XXX人参加。

【正文】：
本次活动的主题是……

活动内容包括……

[详细描述活动过程]

【结尾】：活动取得了圆满成功，参与者表示……
```

### 3. 人物新闻

```
【标题】：XXX：XXX的追梦人

【导语】：近日，记者走访了XXX，了解了XXX的故事。

【正文】：
[人物背景]

[主要事迹]

[他人评价]

[未来计划]

【结尾】：XXX表示……
```

## 字数参考

| 类型 | 参考字数 |
|------|----------|
| 简讯 | 200-300字 |
| 短消息 | 300-500字 |
| 常规报道 | 500-1000字 |
| 深度报道 | 2000-5000字 |

## 注意事项

- ❌ 避免空话套话
- ❌ 避免主观评价
- ❌ 避免模糊表述（"最近""不久"）
- ❌ 避免语法错误和错别字
