# 读后感/观后感模板

## 文体特点

- **情感真实**：表达真实的阅读/观看感受
- **叙议结合**：既要叙述内容，又要发表议论
- **重点突出**：抓住感受最深的一点展开
- **联系实际**：结合自身经历或社会现实

## 模板结构

```
【标题】：《XX》读后感 / 《XX》观后感

【引言】：简要介绍作品基本信息（作者、出版时间、核心内容），引出感受

【概述】：用1-2段概括作品主要内容（不剧透关键情节）

【感点】：选择1-2个感受最深的点深入展开
- 感点一：XXX
  - 原文对应内容：XXX
  - 感悟：XXX
  
【联系实际】：结合自身经历或社会现象谈感受

【结尾】：总结升华，重申感悟，回扣主题

【署名】：XXX（姓名）
     X年X月X日
```

## 写作要点

1. **标题醒目**：标题要体现作品名称和个人感悟
2. **开篇简洁**：引言不宜过长，50-100字为宜
3. **感点明确**：选择一个核心感悟点深入展开，不要面面俱到
4. **叙议得当**：叙述为议论服务，不能大段复述剧情
5. **真情实感**：写出真实的感受，避免空洞的赞美
6. **联系实际**：适当联系自身或现实，使感悟更深刻

## 字数参考

| 学年 | 推荐字数 |
|------|----------|
| 小学 | 300-500字 |
| 初中 | 600-800字 |
| 高中 | 800-1200字 |
| 成人 | 1000-2000字 |

## 示例标题

- 《平凡的世界》读后感
- 《活着》读后感——生命的重量
- 《肖申克的救赎》观后感：希望与自由
- 《朗读者》观后感：文字的力量

## 禁忌提醒

- ❌ 大段复述剧情（超过全文30%）
- ❌ 空泛赞美（"写得真好""太感人了"）
- ❌ 离题万里（与作品内容无关）
- ❌ 人云亦云（写所有人都知道的感悟）
