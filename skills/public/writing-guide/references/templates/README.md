# 文体模板库

本文档提供各类常用文体的写作模板。

> 💡 **使用说明**：当用户请求特定文体模板时，读取对应模板文件。

## 模板索引

| 模板类型 | 文件名 | 适用场景 |
|----------|--------|----------|
| 读后感 | reading-reflection.md | 书籍、电影观后感 |
| 演讲稿 | speech.md | 演讲、发言、致辞 |
| 新闻稿 | news-release.md | 新闻报道、媒体投稿 |
| 调查报告 | survey-report.md | 市场调查、研究报告 |
| 感谢信 | thank-letter.md | 感谢信、表扬信 |
| 辞职信 | resignation-letter.md | 辞职申请 |
| 简历 | resume.md | 个人简历 |
| 自我介绍 | self-introduction.md | 面试、自我介绍 |

---

## 模板使用流程

1. **确认文体**：根据用户需求确定所需模板
2. **读取模板**：从本文档链接获取对应模板
3. **说明特点**：讲解该文体的特点和注意事项
4. **提供示例**：展示完整的示例内容
5. **个性化指导**：根据用户具体情况进行调整建议
