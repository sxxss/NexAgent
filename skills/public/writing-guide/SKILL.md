# 写作指导助手 - SKILL.md

## 概述

这是一个全能写作指导技能，提供三大核心功能：
1. **文章写作辅导** - 构思、素材、结构指导
2. **文本润色优化** - 语法检查、错别字纠正、句式优化、文风调整
3. **文体模板库** - 新闻稿、读后感、演讲稿、报告等各类文体模板

---

## 触发条件

当用户表达以下意图时，触发此技能：
- "帮我写一篇..."
- "写作文"、"写文章"、"写作指导"
- "润色"、"改写"、"优化这段话"
- "检查语法"、"纠正错别字"
- "这是什么文体"
- "给我一个XX模板"（演讲稿、报告、新闻稿等）

---

## 执行流程

### Step 1: 理解需求

首先明确用户的需求类型：

| 输入类型 | 处理方式 |
|----------|----------|
| 已有文本 | 进入"文本润色"流程 |
| 指定主题 | 进入"写作辅导"流程 |
| 请求模板 | 进入"模板提供"流程 |

### Step 2: 执行相应模块

根据需求类型，选择执行：

#### 模块 A: 文本润色
```
输入: 原始文本
-> 语法检查 -> 错别字检测 -> 句式优化 -> 文风调整 -> 输出优化后文本
```

#### 模块 B: 写作辅导
```
输入: 写作主题/标题
-> 确定文体 -> 构思大纲 -> 提供素材 -> 结构建议 -> 输出写作指导
```

#### 模块 C: 模板提供
```
输入: 所需模板类型
-> 加载模板 -> 填充示例 -> 说明特点 -> 输出模板
```

### Step 3: 输出结果

按标准格式输出，格式要求见 references/output-format.md

## 核心功能详解

### 1. 文本润色

#### 1.1 语法检查
- 主谓一致
- 动宾搭配
- 时态正确
- 成分完整

#### 1.2 错别字检测
- 同音字错误
- 形近字错误
- 标点符号错误

#### 1.3 句式优化
- 精简冗余
- 调整长句断句
- 丰富句式变化
- 去除口头禅

#### 1.4 文风调整
| 目标文风 | 特点 | 适用场景 |
|----------|------|----------|
| 正式 | 严谨、规范、商务 | 报告、合同、官方文件 |
| 活泼 | 轻松、有趣、口语 | 社交媒体、博客 |
| 学术 | 客观、引用、专业 | 论文、学术文章 |
| 文艺 | 优美、抒情、意境 | 散文、诗歌 |

### 2. 写作辅导

#### 2.1 审题立意
- 分析题目要求
- 确定写作范围
- 提炼核心观点

#### 2.2 构思大纲
- 引言设计
- 主体结构（2-4个分论点）
- 结尾升华

#### 2.3 素材提供
- 相关名言警句
- 典型事例
- 数据统计

### 3. 文体模板

常用文体模板见 references/templates/

## 边界处理

| 情况 | 处理方式 |
|------|----------|
| 文本过短 (<20字) | 提示无法润色，建议补充内容 |
| 文本过长 (>5000字) | 分段处理，每段独立优化 |
| 明确禁止的内容 | 拒绝修改，说明原因 |
| 非中文文本 | 正常处理，支持中英双语 |
