# ============================================================
# 测试用例集 — demo-text-analyzer skill
#
# 目的：验证 skill 在不同输入场景下的行为是否符合预期。
# 每个用例包含：触发提示词、期望行为、断言检查点。
# ============================================================

# 测试用例 1：正常路径（标准中文段落）
# ──────────────────────────────────────────────────────────
**提示词（Prompt）**
```
帮我分析这段文字：
图神经网络（GNN）通过在图结构数据上进行消息传递，能够有效捕获节点间的
拓扑关系。近年来，GNN 在社交网络分析、推荐系统和生物信息学等领域取得了
显著进展。然而，现有方法在处理异质图时仍面临计算复杂度过高的挑战。
```

**期望行为**
- ✅ 触发 skill（读取 SKILL.md）
- ✅ 读取 `references/output-template.md`
- ✅ 输出包含：摘要、关键词表格、质量评分三个部分
- ✅ 摘要 ≤ 30 字
- ✅ 关键词表格有 5 行，含权重列

**断言检查点**
- [ ] 输出格式与模板一致（有表格，有评分分项）
- [ ] 关键词中出现"图神经网络"或"GNN"
- [ ] 评分在 0–10 范围内

---

# 测试用例 2：边界条件（文本过短）
# ──────────────────────────────────────────────────────────
**提示词**
```
分析一下：AI 很强大。
```

**期望行为**
- ✅ 触发 skill
- ✅ 输出报告，但**附加警告**："文本过短，结果仅供参考"
- ❌ 不应该直接拒绝分析

**断言检查点**
- [ ] 包含"文本过短"相关提示
- [ ] 仍然尝试输出报告（即使质量有限）

---

# 测试用例 3：非触发场景（验证不误触发）
# ──────────────────────────────────────────────────────────
**提示词**
```
1 + 1 等于多少？
```

**期望行为**
- ❌ 不应触发此 skill（这是数学问题，不是文本分析）
- ✅ 直接回答"2"

**断言检查点**
- [ ] 没有输出"文本分析报告"格式
- [ ] 直接给出数学答案

---

# 测试用例 4：英文文本
# ──────────────────────────────────────────────────────────
**提示词**
```
Please analyze this: Graph attention networks leverage the self-attention
mechanism to assign different importance weights to neighboring nodes,
enabling more expressive node representations than classical GCN models.
```

**期望行为**
- ✅ 触发 skill
- ✅ 关键词保留英文原词
- ✅ 摘要可以用中文或英文（不强制）

**断言检查点**
- [ ] 关键词出现 "graph"、"attention" 或 "GCN" 等词
- [ ] 格式仍符合模板

# 测试用例 5：要求详细评分（触发按需加载）
# ──────────────────────────────────────────────────────────
**提示词**
```
分析这段话，并给我详细的评分标准说明：
深度学习模型的可解释性问题一直是学术界关注的焦点。目前主流方法包括
注意力可视化、梯度反向传播和概念激活向量等，各有优劣。
```

**期望行为**
- ✅ 触发 skill
- ✅ **额外读取** `references/scoring-rubric.md`（按需加载触发）
- ✅ 评语中包含对各维度的详细说明

**断言检查点**
- [ ] 提到了"逻辑连贯性"、"信息密度"、"语言清晰度"三个维度
- [ ] 每个维度有具体说明，不只是给分

# 如何使用这些测试用例
#
# 1. 把每条"提示词"复制到 Claude 对话中
