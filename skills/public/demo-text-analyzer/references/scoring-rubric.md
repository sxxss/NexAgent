# 评分细则（Scoring Rubric）

## 逻辑连贯性（0–10）

| 分段 | 标准 |
|------|------|
| 9–10 | 论点→论据→结论链条完整，无跳跃 |
| 7–8  | 结构清晰，偶有轻微跳跃但不影响理解 |
| 5–6  | 存在明显逻辑缺口，需要读者自行补全 |
| 3–4  | 段落间关系混乱，主题漂移 |
| 0–2  | 基本无逻辑结构 |

## 信息密度（0–10）

| 分段 | 标准 |
|------|------|
| 9–10 | 每句话都承载有效信息，冗余极少 |
| 7–8  | 少量填充语句，核心信息完整 |
| 5–6  | 冗余占比约 30%，信息可提炼但需筛选 |
| 3–4  | 大量重复或无意义填充 |
| 0–2  | 几乎全是套话 |

## 语言清晰度（0–10）

| 分段 | 标准 |
|------|------|
| 9–10 | 术语使用准确，句式简洁，歧义为零 |
| 7–8  | 偶有长难句，但整体易读 |
| 5–6  | 多处歧义或术语使用不规范 |
| 3–4  | 语言模糊，读者需猜测作者意图 |
| 0–2  | 表达混乱，基本不可读 |
