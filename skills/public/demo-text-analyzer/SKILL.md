# Demo Text Analyzer — 结构化文本分析 Skill

## 这个 Skill 做什么

接收任意文本输入，按固定流程输出：
1. **一句话摘要**（≤ 30 字）
2. **关键词列表**（5 个，带权重）
3. **质量评分**（0–10，含理由）

---

## 执行流程

### Step 1：读取输入
- 如果用户直接粘贴了文本 → 直接分析
- 如果用户上传了文件 → 先用 bash/view 工具读取内容，再分析
- 如果输入为空 → 礼貌询问，不要假设

### Step 2：参考模板
> ⚠️ 在生成输出之前，**必须先读取** `references/output-template.md`
> 以确保格式一致。这是三层结构中"按需加载"的典型用法。

```
view references/output-template.md
```

### Step 3：执行分析
按模板格式生成输出。若文本超过 500 词，可调用辅助脚本：

```bash
# 调用脚本做词频统计，辅助关键词抽取
# 这展示了 scripts/ 层的使用方式：脚本直接执行，无需加载全文到上下文
python scripts/word_freq.py "<文本>"
```

### Step 4：输出结果
严格按照模板格式呈现，不要自由发挥结构。

---

## 边界条件处理

| 情况 | 处理方式 |
|------|----------|
| 文本 < 20 字 | 提示"文本过短，结果仅供参考" |
| 非中文文本 | 正常处理，关键词保留原语言 |
| 代码片段 | 说明这是代码，质量评分改为"可读性评分" |
| 敏感内容 | 拒绝分析，说明原因 |
